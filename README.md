# StrataState

**StrataState** is an interactive Pushdown Automaton (PDA) simulator built for the Informatics Automata Practicum. It is designed to automatically determine whether a given string is a member of the specific context-free language L = { a^n b^n | n ≥ 1 }.

---

## Key Features

- **Live Execution Tracing**: Instantly evaluates strings and displays a step-by-step trace table detailing state transitions, unread inputs, and stack memory operations (Push/Pop).
- **Stack Memory Visualization**: Visually represents the exact mechanisms of a deterministic PDA, strictly adhering to the LIFO (Last In, First Out) stack principle during execution.

## Tech Stack

- **Language**: C# (.NET 8)
- **Framework**: Windows Presentation Foundation (WPF)
- **Architecture**: Monolithic Code-Behind for straightforward execution and modification.

## Installation

1. Go to the [Releases](https://github.com/devreonid/StrataState/releases) page.
2. Download `StrataState_v1.0.0.exe`.
3. Run the installer and run the executable directly. No additional .NET runtime installation is required!
